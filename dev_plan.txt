The system follows a modern full-stack architecture using Next.js as both frontend and backend framework. Supabase provides a cloud-hosted PostgreSQL database and authentication services. The system is structured using API routes, enabling separation of concerns. Additional integration includes a third-party payment gateway (QPay) for transaction handling.

PHASE 1 - Planning & Requirements (Chapter 1)
Goal: Define what you are building and why
Tasks:
* Finalize technology stack
* Conduct competitor analysis
* Define functional requirements (features)
* Define non-functional requirements (performance, security, scalability)
* Write user stories
Example user story:
"As a customer, I want to search for products so that I can find items quickly."

PHASE 2 - System Design (Chapter 2)
Goal: Design how the system will work
Tasks:
* Database schema design (ERD)
* API structure design
* Folder structure definition
* System architecture diagram
This chapter is VERY important for grading

PHASE 3 - Authentication & User Management (Chapter 3)
Goal: Control who can access what
Tasks:
